# 个人数据保存、账户恢复和运行监控策略

本制度为 PeerGrade 校园试用的运营基线。上线前由学校/课程负责人和系统管理员共同确认适用的保存期限、参与者告知、删除请求受理渠道及备份职责；未确认前不得导入真实教学数据。以下课程数据期限是建议值，不表示已获得任何学校或个人授权。

| 数据类别 | 保存范围与期限 | 控制与处置 |
| --- | --- | --- |
| 账号、班级、任务成员 | 教学任务需要期间 | 仅授权运营者管理账号；密码仅留独立盐哈希，教师不具备网页重置他人密码权限。班级移出不破坏历史任务快照。 |
| 会话 | 最长 12 小时；注销、修改/重置密码时立即撤销相应会话 | 每日运行过期清理预检及明确执行；会话只保存令牌摘要，浏览器不保存密码。 |
| 限流计数 | 保留近期窗口（超过 5 个分钟窗口的旧记录可清理） | 对象只保存摘要，定期清理不会影响当前窗口。 |
| 作业、评价、草稿、复核、采纳和修订、AI 检测快照 | 建议课程结案及争议处理完成后 90 日，按实际授权调整 | 只有相应学生和所属教师可访问授权范围的数据。原 PDF 不落库，证据保留对应文本。到期由授权运营者核对任务、争议、研究同意、导出和恢复依赖后按批准方案清理；不自动级联删除教学记录。 |
| 数据库备份 | 建议滚动 30 日；必要的结案归档按审批延长 | 限权加密存放、定期恢复演练；清理主库后在下一轮轮换时处理对应备份，不直接共享原始归档。 |
| 运行日志 | Web 容器默认最多 3 个约 10 MB 日志文件，运营者定期轮换；不以固定天数替代容量限制 | 只记录脱敏事件、路由模板、状态、时长、进程资源、聚合计数。不要把日志复制到公开项目或截图。 |
| 实验与竞赛证据 | 按另行知情同意的期限，建议只保留必要的匿名化统计 | 实验编号分离于学生身份，原始评价及关联表仅限研究人员，撤回/缺失单独记录。不得将真实学生原文、姓名、模型密钥提交仓库。 |

## 账户修改与恢复

自助修改必须提供原密码、新密码和确认；新密码长度 12–256 字符且与原密码不同。每账号每分钟最多 5 次验证尝试。服务端在同一事务更换哈希并删除所有旧会话，任何旧凭据并发验证都不能在修改后签发新会话。已经发起的请求可能在变更提交前完成；后续请求需要新登录。

忘记密码由学校指定渠道核验本人身份并记录工单；系统运营人员在有数据库访问权限的交互终端操作（不要通过聊天传递密码或密钥）：

```bash
python manage.py reset-password exact_username
# 容器部署时：docker compose exec web python manage.py reset-password exact_username
```

再次输入完全相同的用户名后才允许隐藏输入新密码与确认。密码不作为命令参数；非交互式输入拒绝。重置保留账号 ID、角色和全部教学数据并撤销该账号所有会话；不影响其他账号。管理员通过约定的安全渠道交付一次性临时密码，由本人登录后立即修改。审计工单仅在受控渠道登记操作人、目标账号、时间、身份核验和结果，不记录密码。当前版本不提供网页管理员重置按钮或无核验的短信/邮件恢复流程。

## 日常清理

```bash
python manage.py cleanup-expired          # 只输出待清理数量
python manage.py cleanup-expired --apply  # 仅删除已过期的会话与旧限流窗口
```

生产环境可在运营者确认后每日执行；命令不删除用户、作业、评价、实验数据或仍有效的登录会话。教师或学生的普通网页请求不能执行清理。教学数据到期处置须单独制定有审批的对象清单、先在备份恢复副本演练、核对保留记录和引用一致性，再在维护窗口执行；没有审批或数据范围不明确时不擅自删除。

## 脱敏运维监控

Web 应用通过标准服务日志输出 JSON 事件：

- `service_error`：HTTP 5xx 路由模板、状态码与响应耗时；未匹配路由只保留 `unmatched`。
- `model_check`：`success`、`failed`、`expired` 或 `unavailable`、耗时；不包含供应商响应、模型输入、凭据或作业文本。
- `resource_sample`：每进程在流量（含健康检查）触发下至多每 60 秒输出一次累计 HTTP 状态族计数、模型结果计数、进程 CPU 秒数、峰值驻留内存（平台支持时）、应用所在盘剩余空间和数据库连接池容量/占用。快照不是跨进程聚合，也不代表数据库卷实际剩余空间；重启后计数重新开始。

生产 Uvicorn 关闭原始请求访问日志，HTTP 未处理异常返回统一错误文本，SQLAlchemy 隐藏绑定参数。Caddy 不启用详细访问日志。不要在生产打开请求体或 SQL 参数调试日志。Compose Web 日志按容量轮换；DB/代理基础设施日志仍要限制访问、检查配置和保存期。

运营建议：按 5 分钟窗口统计 5xx/模型失败率，5xx 连续上升或就绪检查失败时核对应用与数据库；模型未配置属于已知降级状态，真实模型连续失败时应维持人工互评并核查配置。由主机监控补足每容器内存/CPU、数据卷可用空间、备份余量、证书有效期、请求延迟。外部告警渠道及阈值须在目标服务器确认后配置；本地合成验收不能替代真实运行监测。所有工单、日志与备份限制为运维角色，禁止暴露给普通网页用户。
