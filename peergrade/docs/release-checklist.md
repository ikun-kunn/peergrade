# 发布前核验清单

本清单记录软件发布门槛、已有历史证据及待执行事项。下列核验项针对**实际待发布提交和目标运行环境**；未完成同等范围的复验不得勾选。开发机上的合成样例、模拟响应和端口预览并不证明正式部署或真实实验完成。

## 功能与数据

- [ ] V2.2 第二批：教师创建班级、邀请码轮换与撤销、学生申请与批准、名单批量导入原子性、移出成员后历史任务保留；其他教师和普通学生不能访问班级管理信息。
- [ ] V2.2 第二批：班级范围内选入任务成员，拒绝未批准和跨班成员；已发布匿名反馈作者发起复核，教师标记、筛选、处理；确认内部标记和身份不出现在学生反馈，原评分和证据不变。

- [ ] V2.2 第一批：搜索/筛选、24 小时未完成提醒、复制历史任务时清除日期与成员。
- [ ] V2.2 第一批：自动保存、刷新恢复、网络失败重试、并发草稿冲突处理、退出或关闭页面有未保存修改时的提醒，验证正式提交后不再写入草稿。
- [ ] 验收任务详情、评语、反馈和教师看板的刷新与深链接；浏览器返回前保存未提交的草稿，失效会话与正在退出的请求不得互相干扰。
- [ ] V2.2 第一批：所属教师 CSV 导出含未交成员和评分摘要；学生、其他教师不能访问；姓名字段不解释为表格公式，不含作业、评语或 AI 输入。

- [ ] 注册新学生，检查密码确认、重名提示、返回登录；登录后确认未被教师选入时没有课程任务，选入后才出现任务。
- [ ] 验证提交不足三人时可延期补交、教师可见未交名单，互评窗口过期且未启动时可结束任务；过期评价不计入学生待办且不可提交。
- [ ] 执行 `npm run build` 后通过 FastAPI 打开应用，确保实际提供最新构建；发布平台排除 `dist` 时执行 `npm run build:publish` 并核对 `webroot` 版本。
- [ ] 用非真实个人数据完成教师建任务、至少三名学生提交、启动互评、提交评价、结束任务、作者查看反馈。
- [ ] 复测文本、文字型 PDF、空白或扫描型 PDF、超过页数和大小限制的文件；确认原始 PDF 不能由评审者下载。
- [ ] 对 3、5、10、30 名提交者检查每人两份、每份两人、无自评和无重复；验证重复启动及分配事务。
- [ ] 在含中英文、换行、表情的正文中选取证据，刷新后定位；确认错误的证据位置、内容摘要或跨作业证据被拒绝。
- [ ] 运行 `npm --prefix frontend test`，检查相同引文能否定位到各自位置、保存草稿遇到 409 时能否保留本地编辑，以及教师发布入口是否更新。
- [ ] 确认只有参与学生与所属教师能查看任务，学生不能读取分配范围以外的作业及其他人的反馈；教师能查看完整记录。
- [ ] 检查零份、一份和两份互评时的反馈、平均分与高分歧统计；确认关闭后不能新增评价。

## AI 与实验

- [ ] 确认可用模型服务及数据处理授权，配置服务端密钥并测试低、中、高质量评价。记录模型版本、测试输入和人工判断，不把模拟响应作为真实模型结果。
- [ ] 运行 `python -m tests.check_quality_model --out quality-check.json`（如使用已获授权的 DeepSeek 官方配置，可加 `--deepseek`），记录四组合成样例的输出、耗时和供应商用量；可加 `--pricing` 提供已核验版本的单价并估算成本。核对请求模型与供应商返回版本，填写每组 `human_assessment`；样例的 `expected_level` 为预设等级。未知费用不应记为零。
- [ ] 验收超时、无效结构、并发、次数限制、检测中/成功/失败计数及质量分统计。确认每条互评总模型调用最多 3 次（所有已预留请求均计入，未配置模型和未通过校验的输入不占用），第 4 次拒绝、达到上限仍可保存草稿和提交评价，AI 分数不计入作品成绩；已有历史检测超过 3 次的记录完整保留。
- [ ] 核对 AI 四类固定问题标签、历史别名归并和未知标签归入 OTHER；非法历史质量分不显示、也不计入质量等级或配对统计。
- [ ] 按[实验方案](experiment.md)组织真实自愿参与者，独立收集前后评价并进行两人人工盲评；记录样本量、缺失数据、分数变化和研究局限。真实数据不得提交至代码仓库。
