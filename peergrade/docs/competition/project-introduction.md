# PeerGrade 项目介绍

PeerGrade 是一套基于原文证据锚定和 AI 反馈质量检测的课程作业互评平台，旨在解决同伴评价容易停留在笼统判断、缺少原文依据和具体修改方向的问题。

教师创建班级、任务和评分量规，学生以文字或 PDF 提交作业。平台在至少三名学生有效提交后进行匿名双评分配，每位提交者评价两份其他作品，同时其作品获得两名评审者。评审者选取原文片段作为证据，并分别撰写优点、问题和改进建议。选区使用 Unicode 码点及原文摘要进行服务端校验，避免位置错配或虚构引文。可选 AI 检测从具体性、依据性和可操作性三个维度提示评语质量，不代写评语，也不改变人工评分。

教师通过看板查看完成率、评分分歧和质量检测记录，发布后学生可以定位收到的匿名反馈、记录是否采纳并提交独立修订版本。教师能够处理复核申请并查看修订历史，学生查看本人历次互评档案。原作业与正式评价保持可追溯。

项目采用 Vue 3、FastAPI、SQLAlchemy 和 Alembic，支持 SQLite 开发及 PostgreSQL 生产配置。V2.4 本机合成验收完成双数据库各 123 项后端测试、26 项前端测试、十账号并发和备份恢复，并在真实桌面及移动浏览器中完成注册、建班、提交、互评、发布、修订、复核和导出。Caddy 回环 HTTPS 链路已验证。真实外部模型效果、正式公网部署及真人教学实验仍需要独立实施和验证。
