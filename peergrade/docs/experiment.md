# 互评质量配对实验方案（待实施）

## 目的和范围

观察 AI 质量提示前后，同一名参与者写出的评价在具体性、依据性、可操作性方面是否发生变化。建议邀请 10—20 名自愿参与者，对不含个人信息的同一组模拟作业进行评价。小样本结果仅供初步探索，不能证明对所有学生有效，也不以模型给出的分数作为效果证明。

## 操作流程

1. 告知参与者模拟作业及评价草稿将由所选模型服务处理；在有权组织实验和获得参与者同意后进行。未同意者不调用外部模型。
2. 参与者阅读同一份作业并写出初始评价，使用质量检测前先保存初稿及证据片段；质量检测记录只能保留**提交给检测的草稿**，未调用检测的初稿不会自动留存。组织者应另行收集合成实验记录，不要以系统日志冒充完整初稿。
3. 参与者查看质量提示，自主选择是否修改，保存修改后的最终评价和证据。
4. 用随机编码打乱全部初稿和终稿的顺序，隐藏作者、版本先后、模型提示和模型分数。两名评价者独立依据下表评分；事先约定如何处理评分分歧。
5. 解除版本编码后配对计算每人的前后差值，并记录未修改、退出和缺失数据。若有缺失，报告有效配对数量及排除理由。

## 人工盲评分级

每项 0—2 分，最高 6 分。以下标准用于本项目探索，并非已验证的学术量表。

| 维度 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 具体性 | 笼统判断，无法定位被评价内容 | 指出章节或主题，但问题描述不清 | 指出可定位的具体内容并解释其表现 |
| 依据性 | 没有依据或引用与观点无关 | 提到相关内容，但依据不完整或联系不清 | 引用或准确指向原文，且能够支撑评价 |
| 可操作性 | 没有修改方向或只有笼统鼓励 | 给出方向，但缺少具体行动 | 给出作者能够实施的具体改进步骤 |

## 记录与分析

每条配对记录至少包括匿名参与者编号、模拟作业编号、初稿与终稿、对应证据、两位盲评者各维度分数、是否修改、是否采纳提示、缺失原因和可选的使用体验反馈。身份对应表与评价数据分开保管，限定访问者和保存期限。

计算每个维度及总分的初稿平均、终稿平均、平均差值，以及改善、持平、下降的人数和比例；报告两个评价者的一致程度与分歧处理方式。展示个案时需确认不含身份线索。软件看板中的 AI 前后分差仅是运行数据，不能代替本方案的人工盲评。

## 状态

本文件是执行方案，没有参与者、盲评数据或实验结论。需要实际组织、收集并分析数据后才能填写结果。

## 可复现的实验工具

在项目根目录（含 `app.py`）执行以下步骤。工具仅处理本地文件，不调用 AI，不自动给评价打分。

1. 将 `docs/experiment-collection-template.csv` 复制到仓库之外的私有实验目录，使用不含学号或姓名的匿名编号，每名参与者一行。`assignment_text` 填同一份模拟作业正文；`before_review`、`after_review` 填三项评价文字；`before_evidence`、`after_evidence` 填对应原文片段（允许为空）。`consent`、`adopted` 用 `yes` 或 `no`。退出或缺失时填写 `missing_reason`，仅使用不含身份信息的原因分类，例如“退出”或“终稿缺失”。未同意者不要收集评价内容。
2. 组织者人工检查作业、评语和证据中的身份线索后，生成盲评包。以下路径是演示命令，请换成自己的私有目录，目标目录必须不存在。

   ```bash
   python experiment.py prepare /private/collection.csv /private/blind
   ```

3. 只向两位评分者分别提供 `blind_packet.txt` 与各自的 `rater_1.csv` 或 `rater_2.csv`。盲评包的记录顺序已经随机打乱，记录标识不含参与者编号或前后版本；**不要共享 `organizer_only.json`，不得共享原始采集表或模型结果**。各自独立填写三个 0–2 的整数分数，不得用空白代替 0。提前约定以两个独立评分的平均值计算；若人为复议，另存复议记录，不覆盖原盲评分数。
4. 两份打分表均完成后，由组织者生成脱敏统计：

   ```bash
   python experiment.py summarize /private/blind/organizer_only.json /private/blind/rater_1.csv /private/blind/rater_2.csv /private/summary.json
   ```

   汇总记录有效配对数、排除原因、是否修改与采纳、三个维度和总分的前后均值及差值、改善/持平/下降比例，以及两名评分者的逐维度完全一致率和平均绝对分差。工具拒绝空样本、未知或重复记录、缺失评分及超出范围分值。不完整的评分需要先补齐；确实无法补齐时应记录排除原因，并由组织者依据原始记录重新准备完整配对，不将缺失分数当零。新输出禁止覆盖已有结果。可选体验反馈单独记录，人工归纳。

5. 仅在完成真实招募、知情同意、实际 AI 提示和人工评分后，才可将汇总结果用于竞赛报告。不要将软件测试中的合成评分当作实际实验数据。

采集表和盲评材料含评价内容，放在仓库以外，限制访问并按知情同意约定清理；只发布经过人工检查的聚合统计和无身份线索的案例。
